# File demo

File mẫu để demo upload (đều là **bản mẫu**, không phải văn bản pháp luật chính thức — xem bản gốc tại vbpl.vn).

```bash
# API đang chạy ở http://localhost:8000
bun run demo:seed     # tạo tài khoản demo, 3 văn bản và upload các file trong thư mục này
```
Tài khoản demo: `demo@trafficlex.local` / `Demo!12345` (chỉ dùng local).
